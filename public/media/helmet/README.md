# Russell glass-shell helmet

- Source archive: `f1-helmet-austrian-gp-2018.zip` (`source/000001474741.glb`).
- Original paint/livery and all image textures were stripped for the smoked/cyan optical-glass landing hero. The output root is `RussellGlassHelmet`, with untextured material roles `HelmetShell`, `Visor`, `AeroClear`, and `Trim`.
- Dense interior/headform geometry, interior padding, the speaker-textured panel, duplicate interior geometry, and the tiny `Face.*` detail cluster were removed. No `#63` decal is baked in.
- The large GLB stays gitignored. Supply it locally as `public/media/helmet/russell-glass-shell.glb`; Vite serves it at `/media/helmet/russell-glass-shell.glb`.
